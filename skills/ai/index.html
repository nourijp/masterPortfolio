      AI & Machine Learning

      Early adopter and power user of AI technology — not just asking questions, but leveraging AI to automate work and amplify creative output.

      AI as a Productivity Multiplier

      I don't just ask AI random trivia questions — I get it to do the work. As an early adopter of AI technology, I've developed expertise in leveraging large language models for practical, production-level tasks. This frees me to focus on higher-level creative and strategic work while AI handles the heavy lifting.

      AI Tools & Platforms

      • ChatGPT / GPT-4: Advanced prompting, custom instructions, API integration
      • Claude / Anthropic: Long-form writing, analysis, and coding assistance
      • GitHub Copilot: AI-assisted code completion and development
      • Image Generation: Midjourney, DALL-E for visual content creation
      • Specialized Tools: Whisper for transcription, AI voice synthesis

      Practical Applications

      • Content Generation: Drafts, outlines, and first passes on writing projects
      • Code Development: Rapid prototyping, debugging, and code review
      • Data Analysis: Pattern recognition, summarization, and insights extraction
      • Automation: Building AI-powered workflows and integrations
      • Learning: Using AI as a personalized tutor and research assistant

      Prompt Engineering

      • System prompts and custom instructions for consistent output
      • Chain-of-thought prompting for complex reasoning tasks
      • Few-shot learning with examples for specialized outputs
      • Context management for long conversations and projects

      Philosophy

      AI is a force multiplier, not a replacement. I use AI to handle repetitive tasks, generate starting points, and accelerate iteration — so I can devote more energy to the creative, strategic, and interpersonal work that humans do best.
